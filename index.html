01. Introduction

A Tree is a non-linear data structure that represents data in a hierarchical manner. It consists of nodes connected by edges, with a single topmost node called the Root.

Root The unique top node with no parent.
Leaf Nodes with no children.
Parent A node with one or more children.
Height The longest path from root to leaf.
